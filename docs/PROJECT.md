# DanceVideoInstructor — 프로젝트 정의서

> 아르헨티나 탱고 영상에서 포즈 스켈레톤을 추출해 **자세(상체 정렬)** 와 **축(axis/balance)** 을 정량화하고,
> "얼마나 잘 추는지 / 무엇이 문제인지"를 근거와 함께 제시하는 분석 시스템.

## 1. 배경과 문제 정의

탱고에서 가장 먼저 교정받는 것은 스텝이 아니라 **자세와 축**이다. 그러나 학습자가 자신의 문제를 인지하기는 어렵다.

- 거울/영상으로 봐도 "뭔가 이상한데 뭐가 이상한지" 언어화가 안 된다.
- 레슨에서 받은 피드백("상체가 무너졌다", "축이 없다")이 **정량적 기준 없이 감각어**로만 전달된다.
- 커플 댄스라 본인 문제인지 파트너 영향인지 분리가 안 된다.
- 개선 여부를 **시간에 따라 추적**할 수단이 없다.

### 해결 가설

단안(monocular) 영상에서 3D 스켈레톤을 복원하고 **중력 기준 좌표계**로 정렬하면,
상체 기울기·척추 붕괴·무게중심 오프셋 같은 지표를 프레임 단위로 측정할 수 있다.
이 시계열을 규칙 기반 루브릭으로 채점하면 **"언제, 어디가, 얼마나" 문제였는지**를 근거 프레임과 함께 제시할 수 있다.

## 3. 사용자 및 시나리오

### 3.1 페르소나

| 페르소나 | 니즈 | 주 사용 기능 |
| --- | --- | --- |
| **학습자 (주 사용자)** | 내 프락티카 영상의 문제 파악, 개선 추적 | 오프라인 리포트, 세션 간 비교 |
| **교사** | 학생에게 근거를 보여주며 설명 | 오버레이 영상, 문제 구간 점프 |
| **개발자(본인)** | 지표 실험/튜닝 | CLI, 지표 시계열 덤프, 평가 하네스 |

### 3.2 핵심 시나리오

**S1. 연습 영상 사후 분석 (v1 핵심)**
1. 삼각대로 찍은 3분짜리 프락티카 영상을 입력
2. 처리 후 리포트 확인: 종합 점수, 카테고리별 점수, 문제 구간 타임라인
3. "01:12–01:20 상체 붕괴(심각)" 클릭 → 해당 구간 오버레이 영상 재생
4. 지표 그래프에서 상체 기울기가 목표 범위를 이탈한 지점 확인

**S2. 세션 간 개선 추적**
- 같은 사람의 여러 세션 리포트를 비교, 지표 평균/분산 추이 그래프

**S3. 레퍼런스 대비 비교 (v2)**
- 레퍼런스 클립을 지정 → DTW 정렬 → 구간별 편차 히트맵

**S4. 실시간 연습 피드백 (v3)**
- 웹캠 앞에서 연습, 축 이탈 시 화면/사운드 경고

## 5. 도메인 용어집

측정 대상을 말로 합의해두지 않으면 지표가 산으로 간다.

| 용어 | 설명 | 관련 지표 |
| --- | --- | --- |
| **에헤 (eje / axis)** | 개인의 수직 축. 무게중심이 지지발 위에 정렬된 상태 | AXI-01, AXI-02 |
| **아플로모 (aplomo)** | 축 위에 안정적으로 "내려앉은" 상태. 바닥과의 연결감 | AXI-02, AXI-04 |
| **아브라소 (abrazo)** | 껴안는 자세(프레임). 클로즈/오픈 엠브레이스 | CPL-02, CPL-03 |
| **콜랩스 (collapse)** | 상체가 무너짐 — 흉추 굴곡, 명치 꺼짐, 어깨 말림 | POS-03, POS-05 |
| **디소시아시온 (disociación)** | 어깨선과 골반선의 회전 분리 | DIS-01 |
| **카미나타 (caminata)** | 걷기. 탱고의 기본. 가슴이 먼저 가고 발이 따라옴 | AXI-03, POS-01 |
| **인클리네이션 (apilado)** | 두 사람이 서로에게 살짝 기대는 자세 (스타일 의존) | POS-01, CPL-03 |
| **리더 / 팔로워** | 제안하는 쪽 / 해석하는 쪽. 성별과 무관 | FR-04 |

> ⚠️ **스타일 의존성**: 살롱 / 밀롱게로(아필라도) / 누에보는 **목표 자세가 다르다**.
> 밀롱게로는 전방 기울기가 정상이고, 누에보는 수직 축이 정상이다.
> 따라서 모든 임계값은 **스타일 프로파일**로 분리한다 (ARCHITECTURE §6.4).

## 6. 성공 기준

### 6.1 제품 성공 기준

| 기준 | 측정 방법 |
| --- | --- |
| SC-1 | 시스템이 지적한 문제 구간 중 **70% 이상**을 경험자가 "맞다"고 동의 |
| SC-2 | 동일 인물의 "좋은 테이크 / 나쁜 테이크"를 지표가 **유의하게 구분** |
| SC-3 | 리포트를 보고 사용자가 **다음 연습에서 무엇을 할지** 말할 수 있음 |
| SC-4 | 같은 장면을 3개 각도에서 찍어도 핵심 지표가 **일관** (NFR-06) |

### 6.2 기술 마일스톤

| 단계 | 산출물 | 완료 조건 |
| --- | --- | --- |
| **M0. 스캐폴드** | 리포 구조, 설정, CLI 골격, 의존성 고정 | `dvi --help` 동작, CI 그린 |
| **M1. 1인 스켈레톤** | 2D 포즈 → 오버레이 영상 | 단일 인물 영상에서 스켈레톤 렌더 |
| **M2. 3D + 중력 정렬** | 3D 리프팅, 바닥/중력 추정, 좌표계 변환 | 카메라 각도 달라도 수직축 일치 |
| **M3. 자세·축 지표** | POS-*, AXI-* 지표 + 시계열 덤프 | 지표 그래프 산출, 눈으로 검증 |
| **M4. 커플 확장** | 다중 추적, 역할 분류, CPL-* 지표 | 커플 영상에서 2인 ID 유지 |
| **M5. 채점 + 리포트** | 루브릭, 문제 검출, JSON/HTML 리포트 | S1 시나리오 완주 |
| **M6. 평가 하네스** | 라벨 세트, 상관 분석, 각도 강건성 테스트 | SC-1, SC-4 측정 가능 |
| **M7. 레퍼런스 비교** | DTW 정렬, 편차 히트맵 | S3 시나리오 |
| **M8. 실시간** | 스트리밍 파이프라인, 경량 백엔드 | S4 시나리오, NFR-02 |

## 7. 검증 전략

정답 라벨이 없는 도메인이므로 **다층 검증**이 필요하다.

| 레벨 | 방법 | 대응 기준 |
| --- | --- | --- |
| **V1. 합성/기하 검증** | 인위적으로 기울인 스켈레톤 입력 → 지표가 기대값 반환 | 단위 테스트 |
| **V2. 카메라 강건성** | 동일 동작을 정면/45°/측면 동시 촬영 → 지표 분산 측정 | NFR-06, SC-4 |
| **V3. 대조군 테이크** | 같은 사람이 "일부러 무너진 자세" vs "정상 자세" 촬영 | SC-2 |
| **V4. 전문가 라벨** | 경험자가 구간별 문제 태깅 (소량, 20~30클립) → 지표와 상관 분석 | SC-1 |
| **V5. 임계값 캘리브레이션** | V4 라벨로 각 지표 임계값 튜닝 (초기값은 가설) | 지표 카탈로그 갱신 |

> 초기 임계값은 전부 **가설**이다. V4 라벨 없이는 "점수"를 신뢰하면 안 되고,
> v1에서는 **점수보다 시계열과 문제 구간 제시**를 주 가치로 삼는다.
